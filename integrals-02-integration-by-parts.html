1מאיפה מגיעה הנוסחה?

אינטגרציה בחלקים היא פשוט כלל המכפלה של הגזירה, קרוא הפוך. נזכיר:

$$(f\cdot g)' = f'g + f g'$$

אם נעביר אגפים ונבצע אינטגרל על שני הצדדים, נקבל את הנוסחה המרכזית:

$$\int f\,g'\,dx = f\,g - \int f'\,g\,dx$$
מה בעצם עשינו כאן? לקחנו אינטגרל שקשה לחשב ישירות, והחלפנו אותו באינטגרל אחר (זה שמימין) שאמור להיות קל יותר. כל הרעיון: לבחור נכון מי \(f\) ומי \(g'\) כך שהאינטגרל החדש יהיה פשוט יותר מהמקורי.

הכלל לבחירה: מי \(f\) ומי \(g'\)?

  • \(f\) — הפונקציה שנגזור. כדאי שתהיה כזו ש"מצטמצמת" כשגוזרים (כמו פולינום, שיורד בדרגה).
  • \(g'\) — הפונקציה שנבצע עליה אינטגרל. חייבים לדעת לחשב את האינטגרל שלה בקלות.
כלל אצבע — סדר עדיפויות ל־\(f\) (מי לגזור) לוגריתם ← פונקציה טריגונומטרית הפוכה (arc) ← פולינום ← מעריכי ← טריגונומטרי.
מה שמופיע ראשון ברשימה — עדיף לבחור אותו כ־\(f\) (זה שגוזרים).

2שלושה מצבים שבהם משתמשים בבחלקים

המצבדוגמה טיפוסיתמה עושים
מכפלה של פולינום בפונקציה אחרת\(\int x e^x\,dx\)הפולינום הוא \(f\) (יורד בדרגה)
פונקציה "בודדת" בלי מכפלה\(\int \ln x\,dx\)חושבים עליה כ־\(1\cdot\ln x\), לוקחים \(g'=1\)
בחלקים חוזר (חילוץ אלגברי)\(\int e^x\sin x\,dx\)עושים פעמיים, מקבלים משוואה ומחלצים
הטריק של הפונקציה ה"בודדת" את \(\int \ln x\,dx\), \(\int \arctan x\,dx\), \(\int \arcsin x\,dx\) לא יודעים לפתור ישירות. הפתרון: לכתוב אותן כמכפלה ב־1, ולקחת \(g'=1\) (כלומר \(g=x\)). ככה מתחילים בחלקים.

3דוגמאות פתורות

דוגמה 1 · מכפלה בסיסית

חשב את \(\displaystyle\int x\,e^x\,dx\).

בוחרים את הפולינום לגזירה:

$$f=x \;\Rightarrow\; f'=1 \qquad g'=e^x \;\Rightarrow\; g=e^x$$

מציבים בנוסחה \(\int fg' = fg - \int f'g\):

$$\int x e^x\,dx = x e^x - \int 1\cdot e^x\,dx$$

האינטגרל שנשאר קל:

$$= x e^x - e^x + C = e^x(x-1)+C$$

שים לב: בזכות הבחירה, \(x\) נעלם (נגזר ל־1) והאינטגרל הפך לפשוט.

דוגמה 2 · הפונקציה ה"בודדת"

חשב את \(\displaystyle\int \ln x\,dx\).

כותבים כ־\(1\cdot \ln x\) ובוחרים:

$$f=\ln x \;\Rightarrow\; f'=\tfrac1x \qquad g'=1 \;\Rightarrow\; g=x$$

מציבים:

$$\int \ln x\,dx = x\ln x - \int \tfrac1x \cdot x\,dx = x\ln x - \int 1\,dx$$

ומקבלים:

$$= x\ln x - x + C$$

דוגמה 3 · בחלקים פעמיים

חשב את \(\displaystyle\int x^2\cos x\,dx\).

סבב ראשון: \(f=x^2,\ f'=2x,\ g'=\cos x,\ g=\sin x\):

$$\int x^2\cos x\,dx = x^2\sin x - \int 2x\sin x\,dx$$

הפולינום ירד מדרגה 2 לדרגה 1 — מתקדמים. נטפל ב־\(\int 2x\sin x\,dx\) בבחלקים שוב.

סבב שני: \(f=2x,\ f'=2,\ g'=\sin x,\ g=-\cos x\):

$$\int 2x\sin x\,dx = -2x\cos x - \int (-2\cos x)\,dx = -2x\cos x + 2\sin x$$

מרכיבים הכל יחד (זהירות עם המינוס מהסבב הראשון):

$$\int x^2\cos x\,dx = x^2\sin x - \big(-2x\cos x + 2\sin x\big) + C$$

$$= x^2\sin x + 2x\cos x - 2\sin x + C$$

דוגמה 4 · חילוץ אלגברי (הטריק החשוב)

חשב את \(\displaystyle I=\int e^x\sin x\,dx\).

כאן שום צד לא "מצטמצם" בגזירה, אבל נראה קסם. נסמן את האינטגרל \(I\).

סבב ראשון: \(f=\sin x,\ f'=\cos x,\ g'=e^x,\ g=e^x\):

$$I = e^x\sin x - \int e^x\cos x\,dx$$

סבב שני על \(\int e^x\cos x\,dx\): \(f=\cos x,\ f'=-\sin x,\ g'=e^x,\ g=e^x\):

$$\int e^x\cos x\,dx = e^x\cos x - \int e^x(-\sin x)\,dx = e^x\cos x + \int e^x\sin x\,dx$$

שים לב: חזר האינטגרל המקורי \(I\)! מציבים בחזרה:

$$I = e^x\sin x - \big(e^x\cos x + I\big) = e^x\sin x - e^x\cos x - I$$

מעבירים אגפים — "מחלצים" את \(I\):

$$2I = e^x\sin x - e^x\cos x \;\;\Rightarrow\;\; I = \frac{e^x(\sin x - \cos x)}{2}+C$$

הטריק: כשבחלקים מחזירים אותך לאותו אינטגרל, מתייחסים אליו כאל נעלם ופותרים משוואה אלגברית. אל תשכח את ה־\(+C\) בסוף.

4שאלות לבדיקת הבנה

נסה לענות בראש לפני שאתה חושף את התשובה.

שאלה 1. באינטגרל \(\displaystyle\int x\ln x\,dx\), מי כדאי לבחור כ־\(f\) (מה שגוזרים), ולמה?

בוחרים \(f=\ln x\) (ולכן \(g'=x\)). הסיבה הכפולה: לפי סדר העדיפויות לוג קודם לפולינום, וגם — אנחנו פשוט לא יודעים לחשב אינטגרל של \(\ln x\) בתור \(g'\), אבל כן יודעים של \(x\). לכן \(\ln x\) חייב להיות זה שגוזרים.

שאלה 2. למה עבור \(\int \arctan x\,dx\) משתמשים בבחלקים למרות שאין שם מכפלה?

כי \(\arctan x\) היא פונקציה "בודדת" שאין לה אינטגרל מיידי בטבלה. הטריק: כותבים אותה כ־\(1\cdot\arctan x\), לוקחים \(g'=1\) (כלומר \(g=x\)), ואז הגזירה של \(\arctan x\) נותנת \(\frac{1}{1+x^2}\) — ביטוי הרבה יותר נוח.

שאלה 3. באינטגרל \(\int e^x\cos x\,dx\), אחרי שני סבבי בחלקים חזרנו לאינטגרל המקורי. זו טעות?

לא — זה בדיוק מה שאמור לקרות. זה הסימן להשתמש בחילוץ אלגברי: מסמנים את האינטגרל ב־\(I\), מקבלים משוואה מהצורה \(I = (\dots) - I\), ומחלצים \(I\) על ידי העברת אגפים.

שאלה 4. בבחלקים על \(\int x^3 e^x\,dx\), כמה פעמים נצטרך להפעיל את השיטה?

שלוש פעמים. כל סבב מוריד את דרגת הפולינום ב־1: מ־\(x^3\) ל־\(x^2\), ל־\(x\), ולבסוף לקבוע. כשהפולינום נעלם, האינטגרל הופך למיידי.

5תרגיל לתרגול עצמאי

תרגיל

חשב את שני האינטגרלים הבאים:

א. \(\displaystyle\int x\sin x\,dx\)     ב. \(\displaystyle\int x^2\ln x\,dx\)

א. בוחרים \(f=x,\ f'=1,\ g'=\sin x,\ g=-\cos x\):

$$\int x\sin x\,dx = -x\cos x - \int (-\cos x)\,dx = -x\cos x + \int\cos x\,dx$$

$$= -x\cos x + \sin x + C$$

ב. לפי סדר העדיפויות, הלוג נגזר: \(f=\ln x,\ f'=\tfrac1x,\ g'=x^2,\ g=\tfrac{x^3}{3}\):

$$\int x^2\ln x\,dx = \frac{x^3}{3}\ln x - \int \frac{x^3}{3}\cdot\frac1x\,dx = \frac{x^3}{3}\ln x - \frac13\int x^2\,dx$$

$$= \frac{x^3}{3}\ln x - \frac{x^3}{9} + C$$

איך לבדוק את עצמך גזור את התשובה שקיבלת. אם חוזרים לפונקציה שבתוך האינטגרל המקורי — הפתרון נכון. זו בדיקה מהירה ששווה לעשות במבחן.
