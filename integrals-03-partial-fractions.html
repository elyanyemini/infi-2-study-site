נושא 3 — שברים חלקיים

אינטגרציה של פונקציות רציונליות \(\frac{p(x)}{q(x)}\)
נושא 3 מתוך 5 · זמן קריאה משוער: כ־25 דקות

1מתי משתמשים בשיטה?

כשצריך לחשב אינטגרל של מנת שני פולינומים:

$$\int \frac{p(x)}{q(x)}\,dx$$

הרעיון המרכזי: אינטגרל של שבר מסובך קשה, אבל אם נפרק אותו לסכום של שברים פשוטים — כל שבר קטן הופך לאינטגרל שאנחנו כבר יודעים (לוג או ארקטנגנס). כל השיטה היא איך מגיעים לפירוק הזה.

שלושת השלבים בקצרה
  1. חילוק פולינומים — רק אם דרגת המונה \(\ge\) דרגת המכנה.
  2. פירוק לשברים חלקיים — מפרקים את השבר לסכום שברים פשוטים ומוצאים מקדמים.
  3. אינטגרל איבר־איבר — כל שבר פשוט הופך ללוג או ארקטנגנס.

2שלב 1 — חילוק פולינומים

עושים את זה רק אם דרגת המונה גדולה או שווה לדרגת המכנה. מבצעים חילוק ארוך עד שהשארית מדרגה נמוכה מהמכנה, וכותבים:

$$\frac{p(x)}{q(x)} = (\text{פולינום}) + \frac{\text{שארית}}{q(x)}$$

למה זה הכרחי? שיטת השברים החלקיים עובדת רק כשהמונה מדרגה נמוכה מהמכנה (שבר "אמיתי"). אם המונה גדול מדי — חייבים קודם לחלק. הפולינום שיצא מהחילוק פשוט לאינטגרל, והשארית עוברת לשלב 2.
דוגמה 1 · חילוק לפני הכל

חשב את \(\displaystyle\int \frac{x^2}{x+1}\,dx\).

המונה מדרגה 2, המכנה מדרגה 1 — חייבים חילוק. מחלקים \(x^2\) ב־\(x+1\):

$$\frac{x^2}{x+1} = x - 1 + \frac{1}{x+1}$$

(בדיקה: \((x-1)(x+1)+1 = x^2-1+1 = x^2\). ✓)

עכשיו אינטגרל איבר־איבר:

$$\int\!\left(x-1+\frac{1}{x+1}\right)dx = \frac{x^2}{2} - x + \ln|x+1| + C$$

3שלב 2 — הפירוק לשברים חלקיים

איך בונים את הפירוק

קודם מפרקים את המכנה למכפלת גורמים. לכל סוג גורם יש "תבנית" שבר משלו:

גורם במכנההשבר שמתאים לו
גורם ליניארי \((x+a)\)\(\dfrac{A}{x+a}\)
גורם ליניארי בחזקה \((x+a)^k\)\(\dfrac{A_1}{x+a}+\dfrac{A_2}{(x+a)^2}+\dots+\dfrac{A_k}{(x+a)^k}\)
ריבועי חסר שורש \((x^2+bx+c)\)\(\dfrac{Ax+B}{x^2+bx+c}\)
שתי מלכודות נפוצות
  • גורם בחזקה \((x+a)^k\) — "רצים" על כל החזקות מ־1 עד \(k\), לא רק על \(k\).
  • גורם ריבועי חסר שורש — המונה חייב להיות מדרגה ראשונה \(Ax+B\), לא סתם קבוע.

איך מוצאים את המקדמים

מכפילים את שני האגפים במכנה המשותף, ואז יש שתי דרכים (אפשר לשלב):

  • הצבת ערכים נוחים של \(x\) — בעיקר השורשים של המכנה, כדי לאפס איברים.
  • השוואת מקדמים — משווים מקדמי \(x^2, x^1, x^0\) בשני האגפים.
דוגמה 2 · שני גורמים ליניאריים

חשב את \(\displaystyle\int \frac{1}{x^2-1}\,dx\).

מפרקים את המכנה: \(x^2-1=(x-1)(x+1)\). תבנית הפירוק:

$$\frac{1}{(x-1)(x+1)} = \frac{A}{x-1} + \frac{B}{x+1}$$

מכפילים במכנה המשותף:

$$1 = A(x+1) + B(x-1)$$

מציבים \(x=1\):   \(1 = 2A \Rightarrow A=\tfrac12\).

מציבים \(x=-1\):   \(1 = -2B \Rightarrow B=-\tfrac12\).

עכשיו אינטגרל איבר־איבר:

$$\int\!\left(\frac{1/2}{x-1} - \frac{1/2}{x+1}\right)dx = \tfrac12\ln|x-1| - \tfrac12\ln|x+1| + C$$

אפשר לאחד ללוג אחד:

$$= \tfrac12\ln\left|\frac{x-1}{x+1}\right| + C$$

דוגמה 3 · גורם בחזקה

חשב את \(\displaystyle\int \frac{x+3}{(x+1)^2}\,dx\).

גורם ליניארי בחזקה 2 — רצים על שתי החזקות:

$$\frac{x+3}{(x+1)^2} = \frac{A}{x+1} + \frac{B}{(x+1)^2}$$

מכפילים ב־\((x+1)^2\):

$$x+3 = A(x+1) + B$$

מציבים \(x=-1\):   \(2 = B\). משווים מקדם של \(x\):   \(1=A\).

אינטגרל איבר־איבר (השני לפי כלל החזקה):

$$\int\!\left(\frac{1}{x+1} + \frac{2}{(x+1)^2}\right)dx = \ln|x+1| - \frac{2}{x+1} + C$$

4שלב 3 — הגורם הריבועי (הכי מסובך)

כשמופיע שבר \(\displaystyle\frac{Ax+B}{x^2+bx+c}\) עם מכנה ריבועי חסר שורש, מפרקים אותו לשני חלקים:

  1. מסדרים את המונה בצורה "נגזרת המכנה + קבוע".
  2. החלק של "נגזרת המכנה חלקי המכנה" נותן \(\ln\) (תבנית \(\frac{f'}{f}\)).
  3. החלק של "קבוע חלקי המכנה" — משלימים לריבוע את המכנה ומשתמשים בנוסחת הארקטנגנס.
תזכורת מנושא 1 $$\int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)|+C \qquad\qquad \int \frac{dx}{x^2+a^2} = \frac1a\arctan\frac{x}{a}+C$$
דוגמה 4 · מכנה ריבועי חסר שורש

חשב את \(\displaystyle\int \frac{x+1}{x^2+4}\,dx\).

נגזרת המכנה היא \((x^2+4)'=2x\). מפצלים את המונה כדי "לייצר" אותה:

$$\frac{x+1}{x^2+4} = \frac{x}{x^2+4} + \frac{1}{x^2+4}$$

החלק הראשון — תבנית \(\frac{f'}{f}\) (עד כדי חצי, כי הנגזרת היא \(2x\)):

$$\int \frac{x}{x^2+4}\,dx = \tfrac12\int\frac{2x}{x^2+4}\,dx = \tfrac12\ln(x^2+4)$$

החלק השני — נוסחת ארקטנגנס עם \(a^2=4\), כלומר \(a=2\):

$$\int \frac{1}{x^2+4}\,dx = \tfrac12\arctan\frac{x}{2}$$

מחברים:

$$\int \frac{x+1}{x^2+4}\,dx = \tfrac12\ln(x^2+4) + \tfrac12\arctan\frac{x}{2} + C$$

מחוץ לחומר הקורס גורם ריבועי בחזקה גבוהה מ־1 (כמו \(\frac{1}{(x^2+a^2)^2}\)) לא נדרש בקורס — לא צריך לדעת לטפל בו.

5שאלות לבדיקת הבנה

נסה לענות בראש לפני שאתה חושף את התשובה.

שאלה 1. לפני שמפרקים לשברים חלקיים את \(\displaystyle\frac{x^3+2}{x^2-1}\), מה חייבים לעשות קודם?

חילוק פולינומים, כי דרגת המונה (3) גדולה מדרגת המכנה (2). רק אחרי שנשארת שארית מדרגה נמוכה מהמכנה מפרקים לשברים חלקיים.

שאלה 2. מהי תבנית הפירוק הנכונה עבור \(\displaystyle\frac{1}{(x-2)^2(x+3)}\)?

$$\frac{A}{x-2} + \frac{B}{(x-2)^2} + \frac{C}{x+3}$$

הגורם \((x-2)^2\) מקבל שני שברים (רצים על שתי החזקות), והגורם הליניארי \((x+3)\) מקבל שבר אחד.

שאלה 3. על גורם ריבועי חסר שורש כמו \(x^2+9\), איזה מונה שמים בשבר החלקי — קבוע או \(Ax+B\)?

מונה מדרגה ראשונה \(Ax+B\). על גורם ריבועי המונה תמיד מדרגה אחת פחות מהמכנה, כלומר ליניארי. (על גורם ליניארי, לעומת זאת, המונה קבוע.)

שאלה 4. את \(\displaystyle\int\frac{2x}{x^2+5}\,dx\) אפשר לפתור מיד בלי פירוק. איך, ומה התוצאה?

המונה \(2x\) הוא בדיוק הנגזרת של המכנה \(x^2+5\) — תבנית \(\frac{f'}{f}\). לכן:

$$\int\frac{2x}{x^2+5}\,dx = \ln(x^2+5)+C$$

6תרגיל לתרגול עצמאי

תרגיל

חשב את \(\displaystyle\int \frac{5x-4}{x^2-x-2}\,dx\).

המונה מדרגה 1, המכנה מדרגה 2 — אין צורך בחילוק. מפרקים את המכנה:

$$x^2-x-2=(x-2)(x+1)$$

תבנית הפירוק:

$$\frac{5x-4}{(x-2)(x+1)} = \frac{A}{x-2} + \frac{B}{x+1}$$

מכפילים במכנה המשותף:   \(5x-4 = A(x+1)+B(x-2)\).

מציבים \(x=2\):   \(10-4=3A \Rightarrow A=2\).

מציבים \(x=-1\):   \(-5-4=-3B \Rightarrow B=3\).

אינטגרל איבר־איבר:

$$\int\!\left(\frac{2}{x-2}+\frac{3}{x+1}\right)dx = 2\ln|x-2| + 3\ln|x+1| + C$$

סדר עבודה שכדאי לזכור למבחן דרגת מונה \(\ge\) מכנה? ← חלק. אחר כך: פרק את המכנה לגורמים ← כתוב תבנית ← מצא מקדמים ← אינטגרל איבר־איבר (לוג / חזקה / ארקטנגנס).
